# Policy and configuration

- Search the API operation and field catalogs before selecting policy or configuration endpoints.
- Separate policy definitions, policy assignments and effective device state.
- Report only fields returned by live API calls; schema fields are not tenant values.
- Treat every state-changing policy/configuration request as approval-required.
- Do not invent unsupported organization permissions or infer them from a role label.
